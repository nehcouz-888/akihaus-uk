Generate & Export Configuration

Sync changes to your source code or export files to deploy to GitHub

Because your site is deployed as a static webpage on GitHub Pages, browser-based changes are temporarily preserved in your current browser cache (LocalStorage).

To make your changes permanent and public for all users, you must update the config files in your repository. Follow the steps below:

Step 1: Export config.js

Download the generated routing file and place it in the root folder of your project, overwriting the old `config.js`.

Step 2: Commit & Push

git add config.js
git commit -m "update: refresh vertical routing link targets"
git push

Run these commands in your command terminal inside the project directory to push changes live.
